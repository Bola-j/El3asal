# El3asal

El3asal is a responsive, Arabic right-to-left landing page for a local honey business. It presents the brand story, product range, quality promises, gallery, customer testimonials, and WhatsApp-based ordering calls to action.

## Technology

- Semantic HTML
- CSS with responsive layouts and reusable visual patterns
- Vanilla JavaScript for scroll-reveal interactions and the dynamic footer year

## Run locally

No build step is required. Open `index.html` in a browser, or serve the folder through any static-file server:

```powershell
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Notes

The page loads gallery images from external image hosts and sends ordering enquiries to WhatsApp. Confirm that all public contact details, product claims, and image licences are appropriate before production deployment.
